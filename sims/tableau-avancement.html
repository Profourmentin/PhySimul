Tableau d’avancement

La méthode en quatre étapes
  1. Écrire l’équation ajustée et compléter la ligne « état initial » avec les quantités de matière (en mol).
  2. Exprimer chaque quantité de matière en cours de réaction : n = ni − coefficient × x pour un réactif, n = coefficient × x pour un produit.
  3. Pour chaque réactif, chercher la valeur de x qui annule sa quantité : x = ni / coefficient. La plus petite valeur est xmax et le réactif correspondant est le réactif limitant. Si les deux valeurs sont égales, le mélange est stœchiométrique.
  4. Remplacer x par xmax (transformation totale) ou par xf (valeur déduite d’une mesure) pour obtenir l’état final. Contrôle : aucune quantité n’est négative, et x a la même valeur pour toutes les espèces.
Pour aller plus loin
  • Une bille représente une quantité de matière (1 mol, parfois 2 ou 5 mol quand il y en a beaucoup), pas une entité réelle : une mole contient environ 6,02 × 10²³ entités.
  • x est exprimé en mol et vaut la même chose pour toutes les espèces. xmax est la valeur maximale que permettent les réactifs ; xf est la valeur réellement atteinte à la fin. La transformation est totale si xf = xmax, non totale si xf < xmax (« transformations totale et non totale » figurent au programme de Première). L’étude quantitative de l’équilibre chimique (quotient de réaction, constante d’équilibre) est en Terminale : elle n’est pas traitée ici.
  • Limites du modèle : seules les quantités de matière sont suivies. Les masses, les volumes de gaz, les concentrations et le solvant ne sont pas traités ici ; ils servent à calculer les quantités initiales (n = m / M, n = C × V).
  • Le tableau d’avancement sert ensuite dans d’autres simulations du site : combustion et énergie de liaison, équilibrer une réaction d’oxydoréduction, titrage colorimétrique.
